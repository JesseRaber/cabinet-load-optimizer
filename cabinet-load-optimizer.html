How the Load Gets Built
  1. Floor = base cabinets, standing upright. They're the only pieces strong enough to carry several layers, so the bottom deck is filled with them first — widest first, so the heavy ones land up front.
  2. Leftover floor = tall & wall cabinets on their side, end panel down. The face pointing up is a solid gable, so the next layer can ride on them.
  3. Plywood over the deck, then the upper layers go on.
  4. Face up is the last resort. A real cabinet is never laid doors-up on the floor. Compatible shallow wall/hutch cabinets may form a protected face-up stack only when every interface passes the active V2 support, coverage, bulk, forward-restraint and stack-depth limits. PAD / BLANKET BETWEEN CABINETS is a crew instruction; the app cannot verify that protection was installed.
  5. Panels, fillers and trim lie flat and fill the gaps between layers.
